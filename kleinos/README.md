# klein_monitors

Dual retro-monitor display for KleinBOTTLE.

Two side-by-side CRT monitor frames:
- **Left (amber)** — app pane: standardized chrome shell for any `KleinApp`
- **Right (green)** — terminal pane: command-line input wired to any executor

## Quick start

```python
from klein_monitors import KleinApp, KleinMonitors

class InventoryApp(KleinApp):
    title = "Inventory"
    def commands(self):
        return [
            ("List items", lambda: "Amulet, iron key, brass lantern"),
            ("Check gold",  lambda: "42 gold coins"),
        ]

monitors = KleinMonitors(root, app=InventoryApp())
monitors.show()
```

## Wiring the terminal to ComputerBackend

```python
from src.computer_backend import ComputerBackend

backend = ComputerBackend()

def execute(text: str) -> str:
    result = backend.execute(text, cwd="/workspace")
    return result.stdout or result.stderr or "(no output)"

monitors = KleinMonitors(root, app=InventoryApp(), executor=execute)
```

## Writing apps

Apps are pure Python — no Tkinter knowledge needed:

```python
class StatusApp(KleinApp):
    title = "Character Status"

    def commands(self):
        return [
            ("Health",   self.health),
            ("Location", self.location),
        ]

    def health(self) -> str:
        return "HP: 18 / 20   Status: Healthy"

    def location(self) -> str:
        return "You are in the Great Hall of Castle Daventry."
```

Each command is a `(label, callable)` pair.  The callable takes no arguments
and returns a string, which the app pane displays in the output area.

## Swapping apps at runtime

```python
monitors.load_app(StatusApp())
```

## Files

```
klein_monitors/
  __init__.py           exports KleinApp, KleinMonitors
  klein_app.py          KleinApp base class
  app_pane.py           AppPane — renders a KleinApp
  terminal_pane.py      TerminalPane — interactive terminal widget
  retro_monitor_frame.py RetroMonitorFrame — bezel + screen container
  monitors.py           KleinMonitors — dual-monitor toplevel
  demo.py               standalone demo (no game required)
  assets/
    monitor_amber.png   left monitor bezel
    monitor_green.png   right monitor bezel
    screen_rect.json    screen placement coordinates
```

## Regenerating bezels

Bezels are generated by `draw_bezel.py` in the pipeline repo:

```bash
# from image-generation-pipeline root
python modules/retro_monitor/draw_bezel.py --style amber \
    --out "C:\Jacob\_GameDESIGN\_KleinBOTTLE\.imports-to-consider\klein_monitors\assets\monitor_amber.png"
python modules/retro_monitor/draw_bezel.py --style green \
    --out "C:\Jacob\_GameDESIGN\_KleinBOTTLE\.imports-to-consider\klein_monitors\assets\monitor_green.png"
```

Both PNGs are committed — no generation needed at runtime.
